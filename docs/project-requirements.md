## 3. 产品和功能要求

### 3.1 页面与交互

- 局域网访问页面后直接进入 ETF 面板，不要求登录。
- 可以添加、查看、删除自选 ETF。
- 支持六类 ETF 策略；未分类 ETF 只计算指标，不生成方向性 B/S 信号。
- 显示历史日 K、RSI14、MA20、BOLL20、成交量和数据状态。
- 显示三种名称：基金简称、基金全称、场内简称。
- 搜索支持六位代码、简称、全称和场内简称。
- 代码精确匹配优先；搜索结果支持分页或加载更多。
- `159307` 必须可通过代码搜索，并展示官方名称：
  - 基金简称：博时中证红利低波100ETF
  - 基金全称：博时中证红利低波动100交易型开放式指数证券投资基金
  - 场内简称：红利低波100ETF博时
- 搜索弹窗中使用系统粘贴、快捷键粘贴或点击结果时，弹窗不能意外关闭。
- 支持 Escape 关闭、焦点恢复、键盘操作和手机浏览器布局。
- 添加、搜索、刷新、错误和数据待确认状态应有清晰反馈。

### 3.2 数据与策略

- SQLite 保存 ETF、自选、日线、修订记录、指标、策略版本和次日条件观察价。
- 历史日线默认使用 `RAW` 未复权口径。
- 数据不足 20 根时，指标显示不可用，不伪造信号。
- 新数据首次采集为 `PENDING`；间隔至少 10 分钟重复采样且数据一致后，才允许启发式标记 `CONFIRMED`。
- 数据源失败时保留上次缓存，不清空数据库。
- 次日条件观察价 API 只对已确认收盘计算；结果必须明确是条件观察价，不是价格预测或交易建议。

## 4. 行情源策略

### 4.1 东方财富 / AKShare

- 东方财富经 AKShare 作为默认历史日线源。
- 不高频重试；遇到 HTTP 502、`Push2RateLimitError` 或明显限流时进入冷却。
- 名录可以使用新浪 ETF 名录补充，但新浪名录不是未经验证的历史日线替代源。

### 4.2 腾讯备用源

- 腾讯历史 K 线只能作为显式配置的候选备用源，默认不替换东方财富。
- 支持的配置目标：
  - `akshare`：仅使用东方财富/AKShare。
  - `tencent`：仅使用腾讯，必须经过真实样本验证后才能启用。
  - `fallback`：东方财富失败后低频尝试腾讯。
- 腾讯返回数据必须统一转换为项目的 `DailyBar` 结构。
- 必须验证交易所前缀：沪市 `sh`，深市 `sz`。
- 只接受已验证的未复权日线；收到前复权或后复权字段时应失败关闭。
- 不能在同一只 ETF 的同一计算序列中静默混用两个数据源。
- 数据库保留 `source` 字段；指标、图表和确认状态使用当前实际成功的单一来源。
- 腾讯未提供成交额时保留 `NULL`，不得用成交量或其他字段伪造成交额。
- 真实接口测试必须低频、限次数，并记录条数、日期、OHLCV 合理性和失败类型，不进行连续重试。

## 6. fnOS 部署要求

### 6.1 部署前必须核实

- fnOS 版本。
- NAS CPU 架构：`x86_64` 或 `ARM64`。
- Docker Engine 和 Docker Compose 是否正常。
- fnOS Docker 图形界面是否支持 Compose 项目。
- 实际存储路径、可用空间和目录权限。
- 8080 端口是否占用。
- NAS 是否能访问 GitHub、镜像仓库和 Python 依赖源。

不得假定数据目录为 `/vol1/docker` 或 `/vol1/1000/docker`。

### 6.2 Compose 约束

- 后端和 Nginx 前端仍使用 Docker Compose。
- 数据必须持久化，优先使用 fnOS 可见的目录挂载；如果从命名卷迁移，先备份并验证 SQLite 和会话/配置数据。
- 后端 API 不映射到局域网宿主端口，只由 Nginx 对外提供 Web 服务。
- 默认仅监听可信局域网，不配置公网端口转发。
- 保留健康检查、自动重启和 SQLite WAL。
- 绝不执行 `docker compose down -v`。

### 6.3 SSH 安全边界

- 凭据文件是 `/Volumes/545s/Temp/cups/login.txt` 的 UTF-8 JSON，必须用 JSON 解析器读取。
- 密码按解析后的原值发送，不 trim、不按冒号切分、不通过 shell 求值。
- 使用系统 `expect` 处理密码提示；密码不得出现在命令行、日志或回复中。
- 保留 `StrictHostKeyChecking=yes`，主机指纹异常时停止调查。
- SSH 只在用户明确授权的范围内执行检查或部署命令。

## 7. 持久化、更新、备份与回滚

- 更新前备份 SQLite 数据库、`.env`、Compose 配置和会话/运行配置。
